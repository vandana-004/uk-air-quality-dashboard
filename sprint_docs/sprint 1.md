
SPRINT 1

Sprint Goal
Develop the first draft of the Air Quality Dashboard where users are able to pick a UK city to see general pollution data.

User Story 1
As a student, I want to select a UK city so that I can analyse its air quality levels.
Tasks:
Identify available UK air quality dataset
Confirm location variables
Clean location data
Create city dropdown menu
Estimated Effort: 8–12 hours

User Story 2(high)
I want to select a UK city from a dropdown menu, so that I can view and analyse air quality data specific to that city.

Independent – Can be developed without other advanced features
Negotiable – UI details can change
Valuable – Delivers visible functionality
Estimable – Small enough to estimate
