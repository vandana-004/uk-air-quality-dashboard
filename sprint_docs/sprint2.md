SPRINT 2

Goal
To develop an advanced multi-dimensional pollution visualisation system that enables comparative analysis of cities using interactive bubble chart.

As a user, I want to compare multiple cities using  charts, so that I can visually analyse pollution severity across pollutants.
Task:
Clean and validate pollutant data
Select the level of PM2.5 (X-axis)
Select the level of NO2 (Y-axis)
Map CO to bubble size
Map ozone to colour scale
Add hover information (City + pollutant values)
