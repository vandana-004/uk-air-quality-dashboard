Sprint 4

Sprint Goal:

Enhance the Air Quality Dashboard by adding predictive insights, trend visualisation, and usability improvements to support deeper environmental analysis.

User Story 1 (Nikhil ) (Medium)
As a user I want to identify the most polluted year so that I can understand the long term air quality trends.

Tasks:
Extract and verify dataset 
Group data by year and calculating average pollutant values.
Identifying the year with the highest pollution value.
Displaying results in the dashboard.
Estimated Effort: 2 hours.

User Story 2 (Nikhil) (Medium)
As a user I want to identify the most polluted month to understand the pollution patterns.

Tasks: 
Extract and verify dataset 
Group data by months and calculating average pollutant values.
Identifying the month with the highest pollution value.
Displaying results in the dashboard.
Estimated Effort: 2 hours

User Story 3 (Nikhil)(High)
As a user, I want to know the best season to visit a selected UK city based on air quality so I can travel accordingly.

Tasks:- 
Extract month from data set and map to season.
Filter data based on selected city.
Grouping data by season and calculating average pollution.
Identify the season with the lowest pollution value.
Displaying results in the dashboard.
Estimated Efforts: 2 hours.


User Story 4 (vignesh)(High): Smart Recommendation System
As a user, I want suggestions based on air quality so that I can take preventive actions.
Tasks:
Define recommendation rules (e.g., “Avoid outdoor activity”, “Wear mask”)
Map AQI levels to suggestions
Display recommendations dynamically based on selected city
Show alerts in user-friendly format (cards/messages)
Estimated Effort: 8–9 hours

User Story 5(vignesh) (Medium): Pollution Hotspot Detection
As a user, I want to identify pollution hotspots so that I can understand critical problem areas.
Tasks:
Identify top polluted locations using threshold logic
Highlight hotspots visually (heatmap / markers)
Rank top 5 polluted cities/areas
Allow filtering by pollutant
Estimated Effort: 8 hours

User Story 6 (vignesh) (High): Correlation Analysis Between Pollutants
As a researcher, I want to see relationships between pollutants so that I can understand how they influence each other.
Tasks:
Calculate correlation matrix (PM2.5, NO2, CO, Ozone)
Display correlation heatmap
Highlight strong positive/negative relationships
Add explanation of correlation results
Estimated Effort: 9–10 hours

User story 7 (Vandana) (High): Site Type Comparison 
As a researcher, I want to compare pollution levels between urban, suburban and rural monitoring sites so that I can understand how location type affects air quality.
Tasks:
Calculate average pollutant levels per site
Build a grouped bar chart comparing site types
Add pollutant dropdown filter
Estimated effort: 6-7 hrs

User Story 7 (Semih) (Medium) : Peak Pollution Hours
As a user, I want to identify the most polluted hours of the day so that I can understand when air quality is at its worst.
Task:
Extract hour from dataset
Group data by hour 
Calculate the average pollution
Identify Peak Hours
Estimated Effort: 5 hours

Sprint Outcome:

Sprint 4 focused on improving the analytical capability of the Air Quality Dashboard by introducing pollution trend analysis, risk alerts, and deeper insights from the dataset. These enhancements help users better understand pollution patterns and make the dashboard more useful for environmental and health analysis.
